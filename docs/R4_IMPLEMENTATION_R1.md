agreement at a starting size below 1 under a matched size policy, the case a cross-policy identity would break).

## Deviations and implementation judgements, each disclosed

1. **Staleness applies to the input actually used.** `max_age_s` is checked on the newest bar and the newest NBBO,
   not on every bar in the warm-up window; an older bar inside the window is history, not a stale input. The
   `FUTURE_INPUT` firewall still applies to every input.
2. **Endpoint availability is checked against the deadline.** §1.4 sets the availability deadline at `t_e + 60 s`,
   so a quote whose event time is at `t_e` and whose receipt lands shortly after is admissible; requiring
   `available ≤ t_e` would have excluded the very observation the algorithm selects.
3. **`v̂` must be consistent with the simulated path.** In the end-to-end fixture, a planted drift with a `v̂` that
   ignored it pushed `|r|/√v̂` to about 11, far outside the training support, and the fitted spread coefficient then
   inflated the modelled spread past 2 so most paths were written off. The fixture now sets
   `v̂ = 15(drift² + h)`. This is a fixture correction, not a code change, and it is worth flagging as an
   operational hazard: the model is a conditional one and extrapolates badly when `v̂` disagrees with the path.
4. **Rule 3 adverse scenarios are a stub.** `engine._adverse` currently records only the base value. The scenario
   set of §5.3 rule 3 (truncation caps, spread ×1.5, extension scale ×1.5, `a_iv` shifted, size floor removed) is
   NOT yet computed, so rule 3 passes trivially. This is an acknowledged gap, not a hidden one.
5. **Attribution is implemented but not exercised end to end.** `comparators.decompose` and
   `attribution.economics`/`forecast_quality` are unit-tested; running the full comparator lattice over a
   population needs the replay harness, which is a separate brick and is not started.
6. **`C_PERM` is not implemented.** The generator and permutation unit exist (`synthetic_world.permute_sessions`)
   but the §6.2 frequency reports are not produced; they gate nothing and belong with the attribution brick.
