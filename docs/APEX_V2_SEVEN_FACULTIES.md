## The non-interference guarantee is structural

The Monday baseline stays clean because the incumbent decision paths
**cannot** read the organism layer, not because we promised not to let
them: `test_no_incumbent_decision_path_imports_the_organism` fails the
suite if any frozen Predator script or module imports `apex.organism`.
Every organism output is stamped `NONE_SHADOW` / `SHADOW_OBSERVATION`.

## What the three scaffolds refuse, by construction

**Cross-Predator Context** (`apex/organism/cross_predator.py`) —
agreement between correlated observers is an echo, not confirmation.
Same-underlying pairs are `HIGHLY_REDUNDANT` by construction; unmeasured
pairs default to `UNKNOWN`, never to independence. Records may not carry
scored fields (`confidence`, `conviction`, `score`) — enforced by test
on keys. `confirmation_claims_permitted: False` until evidence exists.

**Path Intelligence** (`apex/organism/path_intelligence.py`) — the
contract exists; the estimator deliberately does not. A `PathForecast`
whose numbers outrun its pedigree refuses to construct: `NOT_ESTIMABLE`
may carry no numeric quantities, because an invented number wearing
probability's clothes is worse than an honest refusal. The realized-path
recorder accumulates what actually happened (append-only), refusing
R-normalization without a declared 1R. Authority requires `CALIBRATED`.

**Calibration / Uncertainty** (`apex/organism/calibration.py`) — five
named ignorances (data, epistemic, aleatoric, execution, mechanism), and
the single confidence scalar is refused by construction. Probabilistic
claims must be registered **before** their outcomes (resolution refuses
unregistered ids; each resolves exactly once; 0.0 and 1.0 are refused as
non-probabilities). Reliability is bucketed with a pre-declared sample
floor (n ≥ 20 per bucket) — below it the verdict is
`INSUFFICIENT_SAMPLE`, never a curve drawn through noise. The standard:
a model that says 60% and is right 60% is useful; one that says 90% and
is right 60% is dangerous.

## The loop these serve

MARKET → PREDATORS → DISCOVERY → MECHANISM → PATH → CALIBRATION →
GEOMETRY → ASSASSIN → EXPRESSION → CROSS-PREDATOR → ARENA → EXECUTION →
ATTACK → EXIT → OUTCOME → COUNTERFACTUAL MEMORY → ATTRIBUTION → EDGE
HEALTH → DISCOVERY. A loop, not a strategy. We are not trying to find
the strategy; we are building the machine that keeps finding strategies.
