# TOP-1% FITNESS AUDIT (2026-08-15) — not "does it work?" but
"is this the best tool for this exact job?"

Question asked of every layer: *if I were building the best possible
version of this layer for a top-1% intraday trader from scratch today,
would I still choose this implementation?* Verdicts below STRONG become
roadmap items, never Epoch 1 modifications.

| Layer | Job | Verdict | Would I choose it again? / Main gap |
|---|---|---|---|
| Digital World | terrain | **ADEQUATE+** | Yes for the skeleton (PIT-safe, per-facet freshness, online regime). No for the ceiling: events, cross-asset (rates/dollar/credit/VIX term), true liquidity state, industry/factor axes are absent — a top-1% world model sees flows, not just index ETFs. Roadmap: Twin 3.0. |
| Scout | abnormality | **ADEQUATE, honestly unproven** | The attention-not-alpha design is right and rare. But the signal set is hand-declared; an elite scout would learn its own abnormality metric (density/rarity-based) once outcomes exist. The real-tape fix (participation floors) was evidence the declared set needed reality. Measure selectivity first; redesign only with data. |
| Hunter | mechanism | **ADEQUATE by design, thin by count** | Two mechanisms is a principled start, not a top-1% library. Elite version: 5–8 mechanism families incl. catalyst repricing (blocked on events) and cross-sectional pairs. The conjunction-strictness philosophy I would absolutely keep. |
| Oracle: Analog | comparable worlds | **ADEQUATE** | Leakage-proof retrieval I'd keep outright. Uniform declared scales are a v1 crutch — an elite analogue engine learns distance metrics (with governance) and matches on regime/time-of-day structure explicitly. Support honesty (diversity guard) is already elite-grade. |
| Oracle: ML | conditional prediction | **RIGHT SKELETON, placeholder brain** | The contracts (N_eff gates, outcome-token guards, same-schema features) are exactly right. IRLS logistic is deliberately humble; the elite version is gradient boosting + meta-labeling + quantile models under the same contracts. Choose again: contracts yes, model family revisit at first training. |
| Oracle: Simulator | branch futures | **ADEQUATE for diagnosis, not elite** | Single-symbol time-of-day block bootstrap preserves the right structure but ignores cross-sectional correlation and regime conditioning of donors. Elite: regime-conditioned donor pools + factor-consistent joint paths. Its honesty (frequencies, zero authority) is the part to keep forever. |
| Assassin | kill weak trades | **STRONG design, unproven economics** | The stage-not-agent architecture and "anything attacks, only the pipeline authorizes" asymmetry I would choose again without hesitation — it may be APEX's defining idea. Gap: most kill mechanisms are dormant awaiting data; lethal force ungranted; rejection value unmeasured (campaign analysis #2). |
| Swarm | context/adversarial | **STRONG positioning, unproven value** | Tiered scarce-resource scheduling, structured verdicts, role separation, Rule 17 — this is the correct LLM shape and I'd rebuild it identically. Its evidence can only come prospectively; the chair is rented, not owned. |
| Capital | $ worthiness | **STRONG structure, starved inputs** | Monotone caution, sovereign constants, typed forecast socket: choose again. Gaps are inputs, not architecture: no measured spreads (COST_UNKNOWN forever until quotes), paper-NAV sizing template is crude, portfolio state is empty. Elite version arrives with calibrated forecasts, not redesign. |
| Trade Manager | manage thesis | **ADEQUATE with known debt** | Safety counterexamples pass, but the duplicate-law debt (paper.manage vs sealed TradeLifecycle) means I would NOT ship this to paper authorization as-is — unification is the first Phase-5 task (F-11, already on record). |
| Memory | institutional learning | **STRONG for this stage** | The chained ledger + lineage + structural time firewall is the right spine. Elite additions: error-classification taxonomy (Tier-3 forensics), cross-epoch comparison views, and queryable "what fooled us" indices — additive, post-evidence. |
| Router | intelligence spend | **RIGHT idea, proxy metric** | Persistence-horizon routing is honest about what it knows. Elite: fitted decay conditional on setup class + measured edge-decay-during-reasoning closing the loop. The conservative-only law is the keeper. |

## Summary verdict

No layer is miscast — every one is the right *kind* of tool for its job,
which is what architecture reviews can certify. What none of them have
is proof, and three (Assassin economics, Scout selectivity, analogue
distance quality) are exactly what the predeclared replay campaign
measures. The gaps below STRONG are all data-shaped or roadmap-shaped;
none require touching Epoch 1.
