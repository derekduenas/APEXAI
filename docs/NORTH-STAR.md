# APEX North Star (revised 2026-08-15, operator ruling)

**Supersedes** the implicit "validate H1/H3" framing. Does not alter any
signed protocol, amendment, or the credit ledger.

## The objective

> Build APEX into an end-to-end opportunity-discovery and monetization
> engine capable of ingesting the available information, identifying market
> state, generating hypotheses, estimating conditional distributions,
> selecting economically appropriate expressions, constructing portfolios,
> accounting for costs/capacity/risk, and producing a ranked set of
> candidate opportunities. No credit is spent merely to build or explore.
> Credits are reserved for final confirmatory validation of opportunities
> produced by the complete machine.

## What this changes

- **The alpha is not a module.** It is the emergent output of the governed
  research → inference → expression → portfolio → execution loop. H1/H3 and
  APEX-001..004 are INPUTS to the machine, not destinations. The four spent
  credits bought, among other things, the empirical proof that
  "validated alpha" ≠ "profitable strategy" — that lesson is capital.
- **Credit 5 is FROZEN** until the complete machine has run an end-to-end
  historical discovery exercise and produced an opportunity report worth a
  confirmatory look. The A-010 anchor (APEX-004's already-purchased holdout)
  is a separate matter, unaffected by this freeze, at the operator's sole
  discretion via the hand-made token.
- **"No trade" is a first-class output.** A machine that cannot conclude
  "expected edge insufficient after costs and risk — do nothing" is a
  machine that manufactures opportunities.
- **The backtest layer is an evaluator, never an optimizer**: it answers
  "would this have survived realistic implementation", not "which variant
  made the most".

## Build order (v4.0 + operator sequencing)

Track 4 world state → Track 5 exploration/ML governance → Track 6 swarm
producers → portfolio/risk completion → backtest/capacity evaluator →
full-system integration → END-TO-END HISTORICAL DISCOVERY EXERCISE →
inspect the opportunity report → only then decide what earns the final
credit. Twin/Committee unlock on agent calibration, not on a calendar.

## Standing operational blockers (not architecture)

The A-010 token (operator's hand, if/when chosen) and the headless CLI login
(starts every Group B clock).
