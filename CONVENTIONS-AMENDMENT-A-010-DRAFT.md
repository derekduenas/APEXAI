### 3. RATIONALE

3.1 **Attribution requires an anchor** — a full-stack result cannot be
decomposed without a confirmed signal-level result.
3.2 **Holdout-hoarding is a governance failure mode** — an unopened holdout
is an option held because exercising it might hurt, not evidence. §34 does
not currently name this failure mode; this amendment names it.
3.3 **The window is a genuinely mixed-regime test** — 2022-2026 contains a
severe small-cap bear and an extended rally. Factual note, not expectation.

### 4. CONSTRAINTS

4.1 Frozen protocol exactly as written; the registered holdout bar
**t ≥ 2.88** stands, neither raised, lowered, nor reinterpreted.
4.2 Pre-flight: lookahead auditor, protocol pin, ledger chain — any failure
aborts BEFORE the token is spent.
4.3 One evaluation, ever; write-once; hash-chained; anchored; the holdout
burns programme-wide on completion.
4.4 The result is recorded whatever it is, reported with equal prominence
on any outcome, nominal p inflated for the disclosed Bartlett mis-sizing.
4.5 The token remains a human act — never automated, delegated, scripted,
or scheduled.

A-002, A-003, or Rule 17; does not authorise a second look under any
outcome; does not authorise capital, live execution, or paper-track changes;
